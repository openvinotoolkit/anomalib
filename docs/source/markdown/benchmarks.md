# Benchmarks

Benchmark results for anomalib models across datasets, generated by the
[nightly benchmarking pipeline](https://github.com/open-edge-platform/anomalib/blob/main/.github/scripts/benchmark/README.md).

```{important}
Scores come from internal development runs and are intended for relative
comparison between models, not as guaranteed performance claims.
```

## Leaderboard

Models ranked by Image AUROC on the latest available anomalib version for each
dataset. Scores average each category's latest measurements in that version,
giving each category equal weight. Select a model to inspect its category-wise
metrics and history.

```{eval-rst}
.. benchmark-leaderboard::
```

## History

Choose a metric and category, or select **All categories** to compare their trends.
Hover for exact values, drag to zoom, and double-click to reset the view.
Click a chart point to view category-wise metrics for that run. Timestamped nightly
runs remain separate even when they share the same anomalib version. Older results
without timestamps are grouped by version.

The category average includes only categories measured in that run. Category
coverage can change between runs; inspect individual category trends before
interpreting a change in the average as a regression. Missing results are gaps,
not zero scores.
These comparisons support manual inspection, not automatic regression alerts.
